# Contributing

Found a bug, have an idea, or just want to change something? Open an issue or send
a PR. Fixes, docs, little improvements—whatever you think would help.

This is mostly a personal project, so I'll check issues and PRs when I have time.
It might take a while. Just leave a bit of context about what you changed or what
went wrong so I can follow along.

I use **AI-driven development** for this project, so AI-assisted PRs are welcome
too.

If you want to run it locally:

```sh
./dev.sh develop
./dev.sh run --help
./dev.sh test
./dev.sh check
```

Use `.\dev.ps1` on Windows with the same commands. `fmt` formats the code,
`reinstall` updates your installed copy, and `build` makes the release files.
The [dev command notes](docs/development.md) cover the rest.

For security issues, see [SECURITY.md](SECURITY.md).
Contributions use the same [MIT license](LICENSE) as the rest of the project.
